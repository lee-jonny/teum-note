# 틈 · Teum

<img src="Resources/AppIcon-preview.png" alt="틈 앱 아이콘" width="128">

화면 가장자리에 꽂아두는, 나만의 작은 메모 공간.

SwiftUI + AppKit으로 만든 macOS 네이티브 앱입니다. 계정, 서버, 외부 패키지 없이 동작합니다.

## Homebrew 설치와 업데이트

Apple Silicon Mac과 macOS 14 이상에서 다음 명령으로 설치합니다.

```sh
brew tap lee-jonny/teum-note https://github.com/lee-jonny/teum-note.git
brew install --cask lee-jonny/teum-note/teum
```

업데이트할 때는 틈을 종료한 뒤 실행합니다.

```sh
brew update
brew upgrade --cask lee-jonny/teum-note/teum
```

기존에 `willofi/teum-note` 탭으로 설치했다면 틈을 종료하고 새 탭으로 한 번 전환합니다.

```sh
brew tap lee-jonny/teum-note https://github.com/lee-jonny/teum-note.git
brew reinstall --cask lee-jonny/teum-note/teum
brew untap willofi/teum-note
```

직접 설치한 앱이 이미 있으면 Homebrew가 설치 위치 충돌을 알릴 수 있습니다. 메모는 앱 번들과 별도로 저장됩니다. 배포 파일은 개발용 임시 서명 빌드이며, Apple 공증이 없어 macOS에서 최초 실행이 제한될 수 있습니다.

## 소스에서 실행하기

요구 사항: macOS 14 이상, 빌드 시 Xcode와 Swift 6 이상.

```sh
bash scripts/build-app.sh
open dist/Teum.app
```

`dist/Teum.app`을 Applications 폴더로 옮기면 일반 Mac 앱처럼 사용할 수 있습니다. 현재 빌드한 Mac의 아키텍처로 빌드되며, 로컬 개발용 ad-hoc 서명입니다. 외부 배포용 Developer ID 서명·공증·App Store 설정은 포함하지 않습니다.

설치 후에는 Finder의 **응용 프로그램 → 틈**을 열거나 Spotlight에서 **틈**을 검색해 실행합니다. 실행 중에는 메뉴 막대에 아이콘이 나타납니다. Dock에 아이콘이 없는 것은 메뉴 막대 앱으로 설정했기 때문입니다.

GitHub Release의 ZIP을 내려받은 경우 압축을 풀고 `Teum.app`을 응용 프로그램 폴더로 옮길 수 있습니다. ZIP 설치에도 같은 시스템 요구 사항과 서명이 적용됩니다.

## 사용법

- 화면 가장자리에는 폭 18px의 작은 색상 탭만 남습니다. 마우스를 올린 메모 하나만 80px로 부드럽게 펼쳐져 가로 제목을 보여줍니다. 긴 제목은 말줄임표로 표시됩니다. 펼쳐진 제목 위에서는 유지되고, 벗어나면 접힙니다. 선택된 탭은 얇은 테두리로 구분합니다.
- 탭을 클릭하면 메모가 펼쳐집니다. 같은 탭을 다시 클릭하거나 `Esc`, 패널 하단의 접기 버튼으로 닫습니다.
- `⌃⌥Space`로 마지막으로 보던 메모를 펼치거나 현재 패널을 접습니다. 앱을 완전히 종료하면 마지막 메모 기억은 초기화됩니다.
- `⌃⌥]`는 다음 메모, `⌃⌥[`는 이전 메모로 이동합니다. 탭 순서대로 이동하며 끝에서는 처음으로 이어집니다. 패널이 접혀 있어도 이동할 메모를 펼칩니다. 편집창은 클릭했을 때와 같이 선택한 가장자리 탭 옆에 놓이며, 탭이 스크롤 밖에 있으면 먼저 보이게 이동합니다.
- 앱이 활성화되어 있을 때 `⌘N`은 새 메모를 만들고, `⌘W`는 현재 메모를 삭제합니다. 빈 메모는 확인창 없이 삭제되며, 내용이 있으면 확인을 받습니다. 새 메모는 가장 아래에 생깁니다.
- `⌘Z`는 방금 생성하거나 삭제한 메모를 되돌리고, `⌘⇧Z`는 다시 실행합니다. 본문을 편집 중일 때는 글쓰기 실행 취소가 우선합니다. 메모 목록의 실행 취소 기록은 앱을 종료하면 초기화됩니다.
- 단축키가 다른 앱에 점유되어 있으면 메뉴 막대의 이전·다음 메모 항목으로 접근합니다.
- 탭 아래 `+` 또는 편집창 하단의 `+` 버튼으로 메모를 추가합니다. 첫 줄이 탭 제목이 되며 마크다운의 제목·강조 표식은 숨깁니다.
- 메모는 오래된 것부터 위에서 아래로 표시됩니다. 본문을 수정하고 미리보기로 돌아가거나 다른 메모를 열거나 패널을 닫으면, 최근 수정한 메모가 하단의 `+` 위로 이동합니다. 읽기만 하면 순서가 유지됩니다.
- 파일명에 따라 살구, 로즈, 민트, 미스트 블루, 라일락 중 하나를 자동으로 배정합니다. 가장자리 탭과 열린 메모의 색은 같으며 macOS 라이트·다크 모드를 따릅니다. 파일명을 바꾸면 색이 바뀔 수 있습니다.
- 하단 `…` 메뉴에서 저장 상태·글자 수를 확인하거나 메모를 삭제합니다.
- 메뉴 막대의 틈 아이콘에서 왼쪽/오른쪽 배치, 탭 숨기기, 화면 이동, 이 Mac의 메모 폴더 열기, 종료를 선택합니다.
- 메모가 많아지면 탭 영역을 스크롤할 수 있습니다.
- Dock에는 표시되지 않고 메뉴 막대에서 실행됩니다. 로그인 시 자동 실행은 아직 구현하지 않았습니다.

## 마크다운

내용이 있는 메모는 마크다운 서식이 적용된 읽기 화면으로 열립니다. 읽기 화면에서 더블클릭하면 문단 전체가 선택됩니다. 드래그로 문단 일부나 여러 문단에 걸친 범위를 선택한 뒤 `⌘C`로 복사할 수 있습니다. 연필 버튼이나 `⌘⇧M`으로 편집합니다. 빈 새 메모는 곧바로 편집할 수 있습니다.

편집 중에도 제목 크기·굵게·기울임·취소선·코드 서식이 실시간 반영됩니다. 문법 기호는 수정할 수 있도록 연하게 표시합니다. 눈 모양 버튼 또는 `⌘⇧M`으로 문법 기호를 숨긴 읽기 화면으로 돌아갑니다. 원문·한글 조합·실행 취소를 유지하도록 네이티브 텍스트 편집기에 표시 속성만 적용합니다.

편집 중 텍스트를 선택하고 `⌘B` 굵게, `⌘I` 기울임, `⌘⇧X` 취소선, `⌘E` 인라인 코드, `⌘K` 링크를 적용할 수 있습니다. `⌘⇧7`은 번호 목록, `⌘⇧8`은 글머리 목록입니다. 굵게·기울임·취소선·코드·목록을 다시 적용하면 마크다운 표식을 제거합니다. 선택한 텍스트가 없으면 커서에 서식 표식을 넣습니다. 메뉴 막대의 틈 아이콘 → **서식**에서도 같은 명령을 사용할 수 있습니다.

- `# 제목`부터 `###### 제목`까지의 제목
- `**굵게**`, `*기울임*`, `~~취소선~~`, 인라인 코드와 링크
- `- 항목`, `1. 항목`, 들여쓴 목록
- `- [ ] 할 일`, `- [x] 완료` 체크리스트 표시
- `> 인용문`, `---` 구분선
- 백틱 3개 또는 물결표 3개로 감싼 코드 블록

체크리스트 상태는 원문에서 수정합니다. 메모에 자주 쓰는 문법을 지원하는 경량 미리보기이며, 표·이미지·HTML·코드 구문 강조와 복잡한 중첩 블록은 지원하지 않습니다. 렌더링에 외부 서비스나 웹뷰를 사용하지 않습니다.

## 메모 파일과 iCloud Drive

틈노트는 **메모 하나당 Markdown 파일 하나**를 저장합니다. 기본 로컬 폴더는 `~/Library/Application Support/Teum/Notes`입니다. 이전 버전의 `notes.json`은 첫 실행 시 개별 파일로 변환되며 원본은 백업으로 남습니다. `note-index.json`에는 화면 위치와 메모 식별 정보가 저장됩니다. 탭 순서는 Markdown 파일의 수정 시간을 사용합니다. 로컬 메모를 백업하려면 틈을 종료하고 `~/Library/Application Support/Teum` 폴더를 복사합니다.

- **틈 → 이 Mac의 메모 폴더 열기**는 새 메모의 기본 저장 위치와 관계없이 로컬 Markdown 폴더를 엽니다. 별도의 기본 폴더를 골랐다면 **마크다운 폴더 → 새 메모 저장 폴더 열기**로 해당 폴더를 열 수 있습니다.
- 파일명에는 메모의 첫 줄 제목을 사용합니다. 같은 이름이 있으면 `제목 (2).md`처럼 번호를 붙입니다. 첫 줄을 바꾼 뒤 미리보기로 돌아가거나 메모를 닫거나 바꾸면, 로컬 메모와 제목으로 이름이 붙은 연결 메모의 파일명도 바뀝니다. 편집 중에는 본문만 자동 저장합니다. 연결 폴더에서 직접 지정한 별도 파일명은 유지됩니다.
- **새 메모를 iCloud에 저장**하려면 메뉴 막대의 **틈 → 마크다운 폴더 → 새 메모 저장 폴더 선택…**에서 iCloud Drive의 폴더를 고릅니다. 이후 **+** 또는 **⌘N**으로 만들면 그 폴더에 `.md`가 생성되고, 편집하면 그 파일에 저장됩니다. **이 Mac에 새 메모 저장**으로 다시 전환할 수 있습니다.
- **기존 폴더를 표시**하려면 **기존 메모 폴더 연결…**을 사용합니다. 여러 폴더를 연결할 수 있고, 각 폴더 바로 아래의 UTF-8 `.md`, `.markdown` 파일이 가장자리 탭에 나타납니다. 하위 폴더는 개별적으로 연결합니다. 파일 이름은 Finder에서도 관리할 수 있습니다. 틈에서 메모를 삭제하면 이 Mac의 `Recently Deleted` 폴더에 보관하며, 로컬·연결 메모 모두 실행 취소할 수 있습니다.
- **기존 로컬 메모도 공유**하려면 **로컬 메모를 폴더로 복사…**에서 iCloud Drive 폴더를 고릅니다. 복사 기록이 있는 메모는 나중에 사본을 편집했더라도 같은 폴더에 중복 복사되지 않습니다. 이후 공유할 메모는 연결 폴더 쪽에서 편집합니다.
- 다른 Mac에서는 같은 iCloud Drive 폴더를 연결합니다. iPhone에서는 **파일 → 둘러보기 → iCloud Drive**에서 확인합니다. iCloud Drive가 내려받은 변경은 앱을 다시 활성화하거나 **연결한 폴더 새로고침**을 선택하면 반영됩니다.
- 저장할 파일이 외부에서 바뀌었으면 그 메모만 저장을 중단하며, 다른 메모는 계속 저장합니다. **편집 사본 저장**으로 현재 편집을 로컬 Markdown 파일에 보관할 수 있습니다. 읽을 수 없는 파일은 메뉴의 **로컬 메모 문제 보기…**에서 확인합니다. 오프라인에서 같은 파일을 여러 기기로 편집하면 iCloud에서 별도 충돌 해결이 필요할 수 있습니다.
- **연결 해제**는 틈노트의 탭에서 폴더를 숨깁니다. 파일은 해당 폴더에 남습니다. 연결 목록과 새 메모의 기본 저장 폴더는 각 Mac에 기록됩니다.

## 개발

```sh
swift build
swift test
```

Xcode에서는 `Package.swift`를 열어 개발할 수 있습니다. 앱 번들 실행은 위 빌드 스크립트를 사용합니다.

- `Sources/TeumCore`: 메모 모델, Markdown 파일 저장소와 이전 버전 마이그레이션, 화면 배치 계산, 마크다운 블록·제목 처리
- `Sources/TeumApp`: 메모 상태와 자동 저장, SwiftUI 화면, AppKit 패널·메뉴·전역 단축키
- `Tests/TeumCoreTests`: 데이터 왕복 저장, 손상·미지원 데이터 보존, 멀티 디스플레이 좌표, 마크다운 블록·코드·제목 검증
- `scripts`: `.app` 패키징과 코드로 그리는 앱 아이콘

실제 메모와 분리한 개발 데이터로 실행하려면:

```sh
TEUM_DATA_DIR=/tmp/teum-dev dist/Teum.app/Contents/MacOS/Teum
```

## 초안의 범위

하나의 화면 가장자리에 여러 메모 탭을 모아두는 구조입니다. 탭을 자유롭게 드래그해서 화면 곳곳에 배치하거나, 여러 메모 패널을 동시에 열거나, 검색·폴더·첨부파일을 추가하는 기능은 다음 단계입니다. 화면 선택은 현재 실행 중에만 유지되고, 왼쪽/오른쪽 설정은 저장됩니다.
